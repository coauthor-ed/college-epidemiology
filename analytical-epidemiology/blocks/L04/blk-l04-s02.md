## A small P value feels like a certificate

A P value as small as the ones in the previous lesson feels like a certificate of fairness: the gap is too big for chance, so the comparison must be sound. But P measures one rival only, chance. Run the same honest study a hundred times and the odds ratios scatter on both sides of the truth, some high, some low, centred on the real value.

<!-- STEP -->
## Bias misses in one direction, every time

**Bias** is a systematic error built into a study by the way its groups were chosen or questioned. Add one bias to the same study and run it a hundred times again: the whole cloud of results moves to one side and stays there. Repeating the study does not pull it back, and every one of those repeats can still come with a small P value.

> **A P value cannot see bias.**
