## Chance scatters, bias aims

A P value as small as the one in file 3 feels like a certificate of fairness: the gap is too big for chance, so the comparison must be sound. P measures one rival only, chance; it is silent about how the cases and controls were assembled, and that is where bias lives.

Bias is a systematic error built into a study by how its groups were chosen or questioned. Chance misses in all directions; bias misses in one direction, every time, and the P value does not react to it.

> **A P value cannot see bias.**

The target on the right shows the difference. Chance scatters its misses around the centre; bias groups them off-centre, so a hundred repeats land in the same wrong place.
