## Cold-case file 1: a defect that used to be rare

Your first assignment is not a new case. The senior investigator hands you a closed file from 1958 to 1961 and asks you to read it the way people at the time had to, one dated entry at a time. Tap each date on the strip to open its note.

<!-- STEP -->
## 1958: a sleeping drug goes on sale

Thalidomide went on sale in Britain in 1958 as a sleeping drug. It was thought to be safe because it was not a barbiturate, and nothing in the file links it to pregnancy yet.

<!-- STEP -->
## 1961: a cluster that cannot be ignored

At a congress of gynaecologists in 1961, doctors reported a large number of babies born with congenital malformations of a kind that had been rare before. A rare event becoming common is what makes a cluster stand out. Try the switch "what if this defect had always been common?" and the same births disappear into the background, so nobody has a reason to call a congress.

<!-- STEP -->
## 1961: a suspect is named

In the same year, someone suggested that thalidomide might be responsible. That is a suspicion, not a finding, because so far it rests only on doctors noticing the drug in some mothers' histories.

> Senior's note: Before you write a cause next to a cluster, decide what you would need to know to prove it. Keep that list, because every case in this course will use it.
